## Explanation of log_1.log

The log_1.log file records the training process of SynGFN. It contains two key metrics:
1.train mean reward: Represents the average reward of sampled molecules during the current iteration of training.
2.top_10 mean forward reward: Represents the average reward of the top 10 sampled molecules during the current iteration.

During training, the changes in these two key metrics can be monitored. The training process is considered complete when both metrics stabilize, and the loss converges.

## Explanation of syngfn_samples.csv

The syngfn_samples.csv file records the final sampling (generation) results of SynGFN. The total number of sampled molecules can be adjusted via the n_samples parameter in the [main.yaml](config/main.yaml) file. The results file contains the following three fields:
1.trajectory:
Represents the synthetic route of the generated molecule, structured as:

```bash
[reactant1, reactant2, reactant3, rxn1, product_index1, rxn2, product_index2]
```
reactant1-3: Indices of the selected reactants in the [building block library](data/final).
rxn1-2: Indices of the selected reactions in the [reaction template list](data/template.py).
product_index1-2: Indices of intermediate products and the final product in the deduplicated product list generated by the RDKit RunReactants function. This ensures that each trajectory corresponds to a unique and reproducible molecule.

2.readable:
The SMILES representation of the final generated molecule.

3.proxy_vals:
The score of the generated molecule, as evaluated by the proxy model. For example, if the proxy model is a QSAR model, proxy_vals contains the QSAR score for each generated molecule.

## Explanation of syngfn_replay_top_capacity.csv

The syngfn_replay_top_capacity.csv file records the top-K molecules with the highest rewards during the training process. The parameter K can be configured using the replay_capacity parameter in [main.yaml](config/main.yaml). The file contains the following columns:
1.state:
The SMILES representation of the final generated molecule.
2.traj:
The synthetic route for the generated molecule.
3.proxy_val:
The score assigned to the generated molecule by the proxy model.
4.reward:
The reward value for the molecule, which is computed based on the reward function.
5.iter:
The iteration number during training when the molecule was sampled.
